# Спринт по Каиру

## Факты

- В Каирском Музее представлены статуэтки дочерей фараона Эхнатона с вытянутой формой черепа (источник: книга "Спринт по Каиру", глава "Каирский Музей")
- Гид прокомментировала статуэтки так: "у дочерей Эхнатона был дефект, приведший к деформации формы головы" (источник: книга "Спринт по Каиру", глава "Каирский Музей")
- Известные болезни, способные к подобным деформациям черепа, приводят человека к состоянию близкому к состоянию "овоща" (источник: книга "Спринт по Каиру", глава "Каирский Музей")
- После смерти Эхнатона все его реформы были мгновенно свернуты, разрушена его новая столица (источник: книга "Спринт по Каиру", глава "Каирский Музей")
- Фараоны Древнего Египта считались не людьми, а богами или их прямыми потомками (источник: книга "Спринт по Каиру", глава "Каирский Музей")
- В Каирском Музее есть коллекция австралийских бумерангов (не одна штука) (источник: книга "Спринт по Каиру", глава "Каирский Музей")
- Официальная историческая наука утверждает, что суда древних египтян были приспособлены лишь к плаванию по рекам и небольшим каботажным морским рейсам (источник: книга "Спринт по Каиру", глава "Каирский Музей")
- Появление в Древнем Египте коллекций австралийских бумерангов свидетельствует о контактах между Египтом и Австралией в глубокой древности (источник: книга "Спринт по Каиру", глава "Каирский Музей")
- Коллекция бумерангов из гробницы Тутанхамона упоминается гидом (источник: книга "Спринт по Каиру", глава "Каирский Музей")
- Пирамиды на плато Гиза имели серовато-красную облицовку из гранита (источник: книга "Спринт по Каиру", глава "Плато Гиза")
- Облицовка пирамид выполняла не только декоративную, но и прочностную функцию (источник: книга "Спринт по Каиру", глава "Плато Гиза")
- Блоки облицовки имели форму "зубцов", охватывающих внутреннюю кладку пирамиды (источник: книга "Спринт по Каиру", глава "Плато Гиза")
- Блоки облицовки располагались в "шахматном порядке" (источник: книга "Спринт по Каиру", глава "Плато Гиза")
- На некоторых блоках облицовки пирамиды Микерина сохранились выступы, аналогичные южноамериканским мегалитам (источник: книга "Спринт по Каиру", глава "Плато Гиза")
- Блоки облицовки сначала устанавливались на место, а лишь потом шлифовались (источник: книга "Спринт по Каиру", глава "Плато Гиза")
- Точность выравнивания облицовки некоторых исследователей сравнивают с полировкой зеркал астрономических телескопов (источник: книга "Спринт по Каиру", глава "Плато Гиза")
- На границе между отшлифованной и неотшлифованной частями облицовки нет никаких следов сколов гранита (источник: книга "Спринт по Каиру", глава "Плато Гиза")
- Строители использовали закругленную "фрезу" немалых размеров (источник: книга "Спринт по Каиру", глава "Плато Гиза")
- Размеры закругленной "фрезы" совпадают с размерами аналогичных следов в Асуанских каменоломнях (источник: книга "Спринт по Каиру", глава "Плато Гиза")
- Нижние ряды внутренней кладки пирамиды Хефрена состоят из блоков громадных размеров (длина - в рост нескольких человек) (источник: книга "Спринт по Каиру", глава "Плато Гиза")
- Аналогичный стиль кладки наблюдается в Баальбеке (Ливан) (источник: книга "Спринт по Каиру", глава "Плато Гиза")
- Сфинкс был изуродован арабами, сейчас реставрируется кирпичной кладкой (источник: книга "Спринт по Каиру", глава "Плато Гиза")
- Храм Долины возле Сфинкса имеет громадные блоки желтого песчаника и гранитные блоки (источник: книга "Спринт по Каиру", глава "Плато Гиза")
- Гранитные стены Храма Долины имеют сложную форму сопряжения блоков на углах (источник: книга "Спринт по Каиру", глава "Плато Гиза")
- Внешние и внутренние гранитные стены Храма Долины с "прокладкой" из песчаника образуют своеобразный "термос" (источник: книга "Спринт по Каиру", глава "Плато Гиза")

## Концепции

- Версия о вытянутых черепах как признаке божественного происхождения (источник: книга "Спринт по Каиру", глава "Каирский Музей")
- Деформирование черепов как стремление уподобиться богам (источник: книга "Спринт по Каиру", глава "Каирский Музей")
- Контакты между Египтом и Австралией в глубокой древности (источник: книга "Спринт по Каиру", глава "Каирский Музей")
- Альтернативная точка зрения на строительство пирамид (источник: книга "Спринт по Каиру", глава "Плато Гиза")
- Термос-эффект в Храме Долины (источник: книга "Спринт по Каиру", глава "Плато Гиза")
- Кладка с "переходом" блоков с одной стены на другую (источник: книга "Спринт по Каиру", глава "Плато Гиза")

## Персоналии

- **Эхнатон** - фараон, пытавшийся ввести монотеизм в Египте за 1200 лет до Христа (источник: книга "Спринт по Каиру", глава "Каирский Музей")
- **Тутанхамон** - фараон, из гробницы которого происходят бумеранги (источник: книга "Спринт по Каиру", глава "Каирский Музей")
- **Эрнст Мулдашев** - высказывает предположение об инструменте, копия которого хранится в одном из храмов Непала (источник: книга "Спринт по Каиру", глава "Плато Гиза")
- **А. Скляров** - автор (источник: книга "Спринт по Каиру", титульный лист)

## Места

- **Каирский Музей** - место хранения экспонатов, включая статуэтки дочерей Эхнатона и бумеранги (источник: книга "Спринт по Каиру", глава "Каирский Музей")
- **Плато Гиза** - место расположения пирамид и Сфинкса (источник: книга "Спринт по Каиру", глава "Плато Гиза")
- **Великая пирамида** - самая большая пирамида на плато Гиза (источник: книга "Спринт по Каиру", глава "Плато Гиза")
- **Пирамида Хефрена** - вторая пирамида на плато Гиза, закрыта для доступа (источник: книга "Спринт по Каиру", глава "Плато Гиза")
- **Пирамида Микерина** - самая малая из трех пирамид (источник: книга "Спринт по Каиру", глава "Плато Гиза")
- **Сфинкс** - памятник, изуродованный арабами и реставрируемый кирпичной кладкой (источник: книга "Спринт по Каиру", глава "Плато Гиза")
- **Храм Долины** - храм возле Сфинкса с громадными блоками (источник: книга "Спринт по Каиру", глава "Плато Гиза")
- **Асуанские каменоломни** - место с аналогичными следами закругленных "фрез" (источник: книга "Спринт по Каиру", глава "Плато Гиза")
- **Баальбек (Ливан)** - место с аналогичным стилем кладки (источник: книга "Спринт по Каиру", глава "Плато Гиза")
- **Австралия** - страна, с которой были контакты у Египта в глубокой древности (источник: книга "Спринт по Каиру", глава "Каирский Музей")
- **Непал** - страна, где хранится копия предполагаемого инструмента (источник: книга "Спринт по Каиру", глава "Плато Гиза")

## Артефакты

- **Статуэтки дочерей Эхнатона** - экспонаты Каирского Музея с вытянутой формой черепа (источник: книга "Спринт по Каиру", глава "Каирский Музей")
- **Австралийские бумеранги** - экспонаты Каирского Музея, свидетельствующие о контактах с Австралией (источник: книга "Спринт по Каиру", глава "Каирский Музей")
- **Облицовочные блоки пирамид** - гранитные блоки серовато-красного цвета (источник: книга "Спринт по Каиру", глава "Плато Гиза")
- **Закругленная "фреза"** - предполагаемый инструмент для обработки гранита (источник: книга "Спринт по Каиру", глава "Плато Гиза")
- **Гранитные блоки Храма Долины** - блоки со сложной формой сопряжения (источник: книга "Спринт по Каиру", глава "Плато Гиза")

## События

- **Введение монотеизма Эхнатоном** - попытка ввести монотеизм в Египте за 1200 лет до Христа (источник: книга "Спринт по Каиру", глава "Каирский Музей")
- **Разрушение столицы Эхнатона** - после смерти Эхнатона его новая столица была разрушена (источник: книга "Спринт по Каиру", глава "Каирский Музей")
- **Реставрация Сфинкса** - реставрация кирпичной кладкой, скрывающей реальный облик (источник: книга "Спринт по Каиру", глава "Плато Гиза")
- **Ограничение доступа в пирамиды** - вторая пирамида закрыта для доступа, в Великую пирамиду ежедневно продается 150 билетов (источник: книга "Спринт по Каиру", глава "Плато Гиза")

## Методы

- **Шлифовка облицовочных блоков на месте** - блоки устанавливались, а потом шлифовались (источник: книга "Спринт по Каиру", глава "Плато Гиза")
- **Кладка с "переходом" блоков** - блоки на углах "переходят" с одной стены на другую (источник: книга "Спринт по Каиру", глава "Плато Гиза")
- **Использование песчаника как "прокладки"** - между гранитными стенами (термос-эффект) (источник: книга "Спринт по Каиру", глава "Плато Гиза")
