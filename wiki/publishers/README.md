## Описание издательств

### Издательство «Вече»

Основное издательство, выпустившее все книги Андрея Склярова. Специализируется на исторической и научно-популярной литературе.

**Серии книг:**
- «Разгром мифов» (11 книг)
- «Тайны древних цивилизаций» (16 книг)
- Другие работы (4 книги)
