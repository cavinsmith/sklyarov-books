# Урук

**Урук** (sumer. 𒌷𒆠, «город») — один из древнейших и крупнейших городов [[places/sumer|Шумера]].

## Описание

- Храм **Э-Анна** («Небесный Дом») — один из древнейших храмов в мире
- **Протоклинописные таблички** (~5000 из ~5400 найденных) — готовая система бухгалтерского учёта
- **Белый Храм** (78×33 м, на платформе из известняка)

## Значение

[[places/uruk|Урук]] является одним из ключевых памятников для изучения возникновения городской цивилизации и письменности.
