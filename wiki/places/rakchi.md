# Ракчи

**Ракчи** (исп. Raqchi) — археологический комплекс в Перу с двухъярусными стенами: нижняя из мегалитов, верхняя из адобов. Связан с культурой Тиауанако и является важным объектом для изучения инкской архитектуры.

## Местоположение

- Регион Куско, Перу
- Высота: около 3 500 м над уровнем моря

## Археологическое значение

### Двухъярусные стены

- Нижняя часть из мегалитических блоков
- Верхняя часть из адобов (глиняных кирпичей)
- Уникальная технология строительства

### Храм Вируакоча

- Крупнейший храмовый комплекс в регионе
- Посвящён богу Вируакоче
- Свидетельство развития инкской архитектуры
