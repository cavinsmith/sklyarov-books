# Арслантепе

**Арслантепе** (тур. Arslantepe, «Холм львов») — древнее поселение в восточной Турции, одно из важнейших археологических памятников раннего бронзового века. Здесь обнаружены одни из древнейших свидетельств использования сплавов меди с мышьяком.

## Местоположение

- Восточная Турция, провинция Малатья
- На берегу реки Тигр

## Археологическое значение

### Ранняя металлургия

Арслантепе является ключевым объектом для понимания ранней металлургии:

- Содержание мышьяка в копьях: 2,5–3%
- Содержание мышьяка в мечах: 4,5–5%
- Содержание никеля: до 4%
- Эти показатели значительно превышают порог естественных примесей

### Раннее государство

- Одно из древнейших известных государственных образований
- Обнаружены остатки дворцового комплекса с системой зернохранилищ
- Свидетельства социальной стратификации и бюрократического аппарата

## Значение

Арслантепе демонстрирует:

- Раннее использование сплавов меди с мышьяком (arsenical bronze)
- Развитую систему металлургического производства
- Связи между различными культурами бронзового века
