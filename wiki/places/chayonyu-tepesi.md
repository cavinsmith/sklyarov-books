# Чайоню-тепеси

**Чайоню-тепеси** (тур. Çayönü Tepesi) — древнее поселение в восточной Турции, важный объект для изучения ранней металлургии. Здесь обнаружены одни из древнейших свидетельств обработки меди.

## Местоположение

- Восточная Турция, провинция Диярбакыр
- У подножия горного хребта Тавр

## Археологическое значение

### Ранняя металлургия

- Датировка по радиоуглероду: 7500–6800 г. до н.э.
- Обнаружены медные украшения (IX горизонт, рубеж VII–VI тыс. до н.э.)
- Признаки металлургической выплавки

### Содержание мышьяка

- Содержание мышьяка в шиле: 0,8% (выше порога естественных примесей)
- Свидетельство早期 легирования меди мышьяком
- Важный объект для понимания ранней металлургии

## Значение

Чайоню-тепеси демонстрирует:

- Раннее использование меди в регионе
- Свидетельства早期 легирования
- Связи между различными культурами бронзового века
