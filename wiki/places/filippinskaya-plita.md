# Филиппинская плита

**Тип:** Литосферная плита  
**Размер:** наименьшая из крупных плит Земли  
**Расположение:** Западная часть Тихого океана  

Одна из самых маленьких литосферных плит Земли, расположенная в [[places/phippine-sea|районе Филиппинского моря]].

## Описание

- Значительно меньше любой другой плиты на Земле
- Имеет наклон в направлении с юго-востока на северо-запад
- Вместе с [[places/plita-skota]] является одной из двух наименьших плит
- Один из аргументов в пользу гипотезы падения метеорита в [[places/phippine-sea]]
- Границы: на востоке — Тихоокеанская плита, на западе — Евразийская плита

## Геологическое значение

Малый размер плиты может свидетельствовать о катастрофическом событии в геологическом прошлом — падении крупного космического тела, раздробившегосуществующую плиту.
