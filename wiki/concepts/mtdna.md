# МтДНК

Митохондриальная ДНК — ДНК, находящаяся в митохондриях клеток. Используется для отслеживания материнской линии наследования.

## Описание

МтДНК наследуется только по материнской линии (от матери к детям). Она мутирует с постоянной скоростью, что позволяет использовать её для определения времени расхождения материнских линий. Анализ мтДНК играет ключевую роль в изучении миграций древних людей и генетических связей между популяциями.

## Применение

- Определение материнских гаплогрупп
- Датирование времени жизни общих предков
- Изучение миграционных маршрутов древних людей
