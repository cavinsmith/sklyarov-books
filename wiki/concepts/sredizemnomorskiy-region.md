# Средиземноморский регион

Географический регион, центральный в исследованиях [[people/andrey-sklyarov|Андрея Склярова]]. В работах рассматривается как один из ключевых регионов [[guides/paleokontakt|палеоконтакта]].

## Основные положения

- Регион сосредоточения древних цивилизаций
- Место контакта разных культур
- Один из центров [[concepts/drevnie-bogi|«богов»]]
- Множество мегалитических сооружений

- [[places/hatussa|Хатусса]]

## Роль в [[concepts/alternativnaya-istoriya|альтернативной истории]]

- Место зарождения монотеизма
- Центр борьбы между «богами»
- Источник знаний для западной цивилизации
