# Менора

**Менора** — светильник из чистого золота с семью ветвями, один из главных символов иудаизма. Согласно Библии, был сделан по повелению Бога для скинии.

## Описание

- Семисвечник из чистого золота
- Семь ветвей: три с каждой стороны и одна центральная
- Западная лампада горела чудесным образом (по преданию)
- Главный атрибут скинии и Иерусалимского храма
- Символ непрерывности иудейской традиции
