# Коллективное бессознательное

Концепция Карла Юнга — общий пласт бессознательного для всех людей, содержащий архетипы. В работах [[people/andrey-sklyarov|Андрея Склярова]] коллективное бессознательное используется для объяснения сходства мифов у несвязанных культур.

## Основные положения

- Общий пласт бессознательного для всех людей
- Содержит архетипы — универсальные образы
- Объясняет сходство мифов у разных культур
- Связь с [[concepts/egregor|эгрегорами]]
- Связь с [[concepts/noosfera|ноосферой]]
