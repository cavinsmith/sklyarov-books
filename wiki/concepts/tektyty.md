# Тектиты

Природное стекловидное вещество, образовавшееся при столкновении метеорита с Землёй. Используются для датирования катастрофических событий. В работах [[people/andrey-sklyarov|Андрея Склярова]] тектиты рассматриваются как свидетельство глобальных катастроф.

## Свойства

- Стекловидная структура (от лат. tectos — «плавленый»)
- Тёмный зелёный или чёрный цвет
- Твёрдость: 5-7 по шкале Мооса
- Плотность: 2,3-2,6 г/см³
- Содержание SiO₂: 65-80%
- Мелкие пузырьки газа внутри (указывают на быстрое остывание)

## Классификация

### По географическому распространению
- Австрало-азиатское поле (Малайзия, Австралия, Южный Китай)
- Евразийское поле (Чехия, Германия, Белоруссия)
- Североамериканское поле (Техас, Джорджия)
- Южноамериканское поле (Аргентина, Бразилия)

### По возрасту
- Основные группы: ~35 млн, ~15 млн, ~1 млн лет назад
- Молодые тектиты (австралиты): ~0,7 млн лет

## Происхождение

### Гипотеза ударного происхождения
- Образуются при ударе метеорита о Землю
- Температура плавления: >1700°C
- Мгновенное остывание расплавленной породы
- Связь с [[concepts/potop|глобальными катастрофами]]

### Гипотеза лунного происхождения
- Возможное лунное происхождение (гипотеза О'Кифа и Шарма)
- Образование при ударе метеорита о Луну
- Выбрасывание расплава на Землю

## Роль в датировке катастроф

- Тектиты — индикаторы крупных столкновений
- Связь с [[concepts/udarnaya-zima|ударной зимой]]
- Используются для датировки [[concepts/pleistocene-catastrophe|плейстоценовой катастрофы]]
- Глобальное распространение указывает на масштаб события

## Связь с концепцией Склярова

- Тектиты — свидетельство [[concepts/cosmic-catastrophes|космических катастроф]]
- Могут быть связаны с [[concepts/potop|Потопом]] XI тысячелетия до н.э.
- Используются для критики [[concepts/geokhronologiya|геохронологии]]
