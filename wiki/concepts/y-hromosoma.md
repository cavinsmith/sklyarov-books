# Y-хромосома

Половая хромосома, определяющая мужской пол. Используется для отслеживания отцовской линии наследования.

## Описание

Y-хромосома наследуется только по отцовской линии (от отца к сыну). Она содержит небольшое количество генов и мутирует с постоянной скоростью. Анализ Y-хромосомы позволяет определить отцовские гаплогруппы и проследить миграции древних мужчин.

## Применение

- Определение отцовских гаплогрупп
- Датирование времени жизни общих предков
- Изучение патрилинейных связей
