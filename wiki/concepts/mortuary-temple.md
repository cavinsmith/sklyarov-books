# Мемориальный храм

**Описание:** Храм, построенный для почитания усопшего фараона. По версии Склярова, мемориальные храмы связаны с [[concepts/bogi-vysokorazvitaya-civilizaciya|технологиями богов]].

## Примеры мемориальных храмов

- Храм Хефрена (Гиза) — гранитный храм у основания пирамиды
- Храм Исиды (Гиза) — восстановлен Хуфу, согласно Инвентарной стеле
- Храмы в Долине Царей
- [[places/valley-of-kings|Долина Царей]] — погребения фараонов Нового царства

## Функции

- Ритуалы почитания усопшего
- Связь с [[concepts/pyramid-effect|эффектом пирамид]]
- Хранение артефактов «богов»
- Астрономическая ориентация
