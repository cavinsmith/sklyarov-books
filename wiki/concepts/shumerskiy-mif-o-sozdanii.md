# Шумерский миф о создании мира

**Другие названия:** Энума Элиш (вавилонская версия), Шумерская космогония  
**Язык:** Шумерский / Аккадский  
**Датировка:** ~XXI–XVIII века до н.э.

---

## Описание

Шумерский миф о создании мира — комплекс мифологических текстов, описывающих возникновение Вселенной, богов и человека в шумерской традиции. Является одним из древнейших описаний космогонии в мировой культуре.

---

## Основные элементы мифа

### 1. Изначальный хаос

- До сотворения мира существовали только **Апсу** (пресная вода) и **Тиамат** (солёная вода)
- Из их смешения возникли первые боги

### 2. Рождение богов

| Бог | Роль |
|-----|------|
| **Ану** | Небо, верховный бог |
| **Эа (Энки)** | Мудрость, вода |
| **Энлиль** | Воздух, ветер |
| **Нинхурсаг** | Земля, плодородие |

### 3. Война богов

- **Тиамат** (хаос) противостояла молодым богам
- **Мардук** (вавилонская версия) победил Тиамат
- Из тела Тиамат был создан мир

### 4. Создание человека

- Человек был создан из **глины** и **крови** побеждённого бога (Кингу)
- Цель создания — **работать на богов** (пахать землю, приносить жертвы)

## Ключевые концепции

| Концепция | Описание |
|-----------|----------|
| **Апсу** | Изначальная пресная вода |
| **Тиамат** | Изначальная солёная вода (хаос) |
| **Мардук** | Бог-победитель Тиамат |
| **Кингу** | Супруг Тиамат, убитый для создания человека |
| **Дilmun** | Священный остров, место обитания богов |

---

## Связь с работами Склярова

В контексте работ [[people/andrey-sklyarov|Андрея Склярова]]:

- **Создание человека** — интерпретируется как [[concepts/gennaya-inzheneriya|генная инженерия]] со стороны [[concepts/civilization-of-gods|цивилизации богов]]
- **Цель создания** — человек был «рабочей силой» для богов
- **Тиамат** — возможный прототип [[concepts/faeton|Фаэтона]] (разрушенная планета)
- **Ану** — предположительно один из руководителей «богов»
