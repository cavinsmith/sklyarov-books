# Биреакционная схема

**Биреакционная схема** — метод выплавки металлов, основанный на двух последовательных химических реакциях.

## Применение

- Использовалась для получения железа из шеелита (вольфрама) в примитивных печах при 1100–1150°C
- Тигли для биреакционной схемы — сосуды с закруглённым дном
- Позволяла получать металлы при температурах, недоступных для прямого восстановления

## Контекст

Упоминается в [[books/22-metally|книге «Металлы — дар небесных богов»]] как один из методов древней металлургии.
