## Описание проектов

### Проект Наска-Пальпа

Цель: Изучение геоглифов Наски и Пальпы с использованием современных технологий дистанционного зондирования и 3D-моделирования.

### Проект «Третье тысячелетие»

Цель: Комплексное исследование истории цивилизаций с использованием междисциплинарного подхода.
