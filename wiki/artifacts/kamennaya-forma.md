# Каменная форма для отливки топоров

**Каменная форма для отливки топоров** — древняя литейная форма, обнаруженная в Сардинии.

---

## Описание

- Каменная форма для отливки бронзовых топоров
- Свидетельство развития литейного производства в Сардинии
- Древнейшие известные литейные формы в регионе
- Использовалась для массового производства бронзовых орудий

---

## Значение

Каменные формы для отливки свидетельствуют о:
- Развитой металлургической традиции
- Масштабном производстве бронзовых орудий
- Высоком уровне технических знаний
