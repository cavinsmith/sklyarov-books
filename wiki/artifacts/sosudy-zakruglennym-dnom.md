# Сосуды с закруглённым дном

**Сосуды с закруглённым дном** — тигли для биреакционной схемы выплавки металлов.

## Источники

- [[books/22-metally|«Металлы — дар небесных богов»]] — глава «Доступное богам недоступно людям»: ритуальные сосуды с закруглённым дном из Древнего Египта как тигли для биреакционной схемы. Форма нелогична для обычной посуды, но функциональна для тиглей, которые нужно переворачивать вверх дном.

## Назначение

- Использовались как тигли для **биреакционной схемы** выплавки металлов
- Закруглённое дно обеспечивало оптимальный температурный режим
- Свидетельство высокого уровня металлургических знаний
