# Галенит

**Галенит** (PbS) — сульфид свинца, основная руда этого металла в древности.

## Основные сведения

- Химическая формула: PbS
- Цвет: свинцово-серый с металлическим блеском
- Твёрдость: 2,5–2,75 по шкале Мооса
- Удельный вес: 7,4–7,6 (аномально тяжёлый минерал)
- Образует кубические кристаллы

## Применение в древности

- Основной источник свинца для древних металлургов
- Свинец использовался для водопроводных труб (Рим)
- Применялся в производстве化妆品 и лекарств
- Использовался в литейном деле
