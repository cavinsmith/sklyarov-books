# Долинный храм Гизы

**Долинный храм Гизы** — один из храмов, входящих в комплекс пирамид [[places/giza-plateau|Гизы]].

## Источники

- [[books/29-sprint-po-kairu|«Спринт по Каиру»]] — глава «Плато Гиза»: храм возле Сфинкса с громадными блоками.
- [[books/12-tsivilizaciya-bogov-egipta|«Цивилизация богов древнего Египта»]] — глава «Криволинейные поверхности»: стены Гранитного Храма в Гизе имеют закругленные внутренние углы, требующие фрезы с соответствующим закруглением.

## Описание

- Расположен у подножия [[places/giza-piramidy|Великой пирамиды]]
- Построен из гранитных блоков
- Содержит следы высокоточной обработки камня
