# Мадридский кодекс

**Хранение:** Национальный археологический музей, Мадрид, Испания
**Материал:** кора дерева (amate)
**Датировка:** предположительно X-XV вв. н.э. (скопирован с более раннего оригинала)
**Страницы:** 78
**Язык:** иероглифы майя

Самый длинный из сохранившихся кодексов майя. Содержит астрономические таблицы и описания ритуалов.

---

## Ключевые факты

- Самый длинный из четырёх кодексов майя (78 страниц)
- Содержит таблицы для определения ритуальных дней
- Включает астрономические расчёты
- Описывает церемонии, связанные с сельским хозяйством
