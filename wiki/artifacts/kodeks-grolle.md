# Кодекс Гролле

**Хранение:** Национальная библиотека Франции, Париж
**Материал:** кора дерева (amate)
**Датировка:** предположительно VIII-X вв. н.э.
**Язык:** иероглифы майя

Один из четырёх сохранившихся кодексов майя. Содержит астрономические и ритуальные тексты.

- Один из четырёх известных кодексов майя
