# Шпульки из горного хрусталя

**Шпульки из горного хрусталя** — артефакты, обнаруженные в Мексике, которые по форме напоминают шпульки современных швейных машин.

## Особенности

- Изготовлены из **горного хрусталя** — материала твёрдостью 7 по шкале Мооса
- Требуют для обработки **алмазного инструмента**
- Форма и точность изготовления указывают на использование высокотехнологичных методов обработки

## Альтернативный артефакт

Аналогичные шпульки обнаружены из **обсидиана** (вулканического стекла), что также требует высокоточных методов обработки.
