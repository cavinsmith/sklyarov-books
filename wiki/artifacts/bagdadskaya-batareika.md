# Багдадская батарейка

**Место обнаружения:** Хузестан, Ирак (древний Селевкидский/Парфянский период)  
**Датировка:** ~250 г. до н.э. — 220 г. н.э.  
**Материал:** Керамика, медь, железо

---

## Описание

«Багдадская батарейка» — collective название для нескольких керамических сосудов, обнаруженных в Ираке, которые, по мнению ряда исследователей, могут представлять собой древние гальванические элементы — источники электрического тока.

---

## Конструкция

Типичный экземпляр состоит из:

1. **Керамического корпуса** (горшок) диаметром ~13 см
2. **Медной цилиндрической трубки** (диаметр ~26 мм), вставленной в горшок
3. **Железного стержня** (диаметр ~6 мм), вставленного в медную трубку
4. **Асфальтовой пробки** — герметизация и изоляция

---

## Гипотеза об электрическом назначении

### Аргументы за

- При заливке в сосуд раствора лимонной кислоты (или уксуса) устройство вырабатывает электрический ток ~1-2 вольта
- Медь и железо образуют два электрода с разным электрохимическим потенциалом
- Кислотный раствор выступает электролитом
- Возможно использование для:
  - **Гальванопластики** — покрытия предметов металлом
  - **Медицинских целей** — обезболивающий эффект электрического тока
  - **Религиозных ритуалов** — создание «магических» ощущений

### Аргументы против

- Нет проводов или контактов для подключения
- Нет свидетельств использования электричества в античности
- Устройство могло быть просто контейнером для хранения свитков (медная трубка — футляр для папируса)
- Энергии устройства слишком мало для практического применения

---

## История находки

- **1936 год:** Немецкий археолог **Вильгельм Кёниг** обнаружил сосуды в окрестностях Багдада
- Кёниг опубликовал гипотезу об электрическом назначении в 1938 году
- После Второй мировой войны тема получила широкую огласку

---

## Эксперименты

### Электрический ток

При заполнении лимонной кислотой:
- Напряжение: **~1 вольт**
- Сила тока: **~0,1 мА**
- Для увеличения тока можно соединить несколько элементов последовательно

### Гальванопластика

Экспериментально подтверждено: несколько соединённых элементов способны наносить медное покрытие на поверхность за несколько часов.

## Альтернативные трактовки

| Версия | Описание |
|--------|----------|
| **Батарейка** | Гальванический элемент для выработки тока |
| **Контейнер для свитков** | Медная трубка — футляр для папируса |
| **Сосуд для хранения** | Обычный керамический сосуд |
| **Медицинское устройство** | Использование слабого тока для обезболивания |
