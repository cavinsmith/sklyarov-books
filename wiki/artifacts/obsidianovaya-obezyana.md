# Обсидиановая обезьяна

**Описание:** Скульптура обезьяны из обсидиана, обнаруженная в Мексике. Отличается точно круглой формой тела, достигнутой без использования гончарного круга -- технологии, которая не была известна в Мesoамерике.

**Книги:**
- [[books/13-meksika-bez-krivyh-zerkal]]

**Ключевые факты:**
- Материал: обсидиан (твёрдостью 5-6 по шкале Мооса)
- Форма: точно круглая
- Технология: обработка без гончарного круга
- Гончарный круг не был известен в Мesoамерике
- Для достижения такой круглости необходим токарный станок
- Хранится в Национальном музее антропологии в Мехико
- Свидетельство высокотехнологичной обработки

**Связанные сущности:**
