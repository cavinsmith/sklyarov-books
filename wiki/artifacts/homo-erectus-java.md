# Homo erectus Java

**Homo erectus Java** (Яванский человек, Питекантроп) — окаменелые останки вида Homo erectus, обнаруженные на острове [[places/java|Ява]]. Ставят под вопрос традиционную модель «Исход из Африки».

## Основные сведения

- **Первооткрыватель:** Эжен Дюбуа (1891 год)
- **Первоначальное название:** Питекантроп («обезьяночеловек»)
- **Место находки:** река Solo, остров [[places/java|Ява]]
- **Датировка:** от 1,5 млн до 108 тыс. лет назад
- **Останки:** черепа, зубы и фрагменты скелета

## Значение находки

- Ставит под вопрос традиционную модель «Исход из Африки»
- Указывает на возможность параллельного развития человекообразных существ в Азии
- Свидетельствует о более широком расселении ранних гоминид
