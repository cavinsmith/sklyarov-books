# Николай Черных

**Описание:** Советский и российский археолог, соавтор «Дендрохронологии Восточной Европы» (вместе с Б.А. Колчиным). Один из ведущих специалистов по дендрохронологии и археологии Северной Евразии.

**Ключевые факты:**
- Соавтор фундаментального труда «Дендрохронология Восточной Европы» (вместе с Б.А. Колчиным)
- Специалист по дендрохронологии — методу датирования по годичным кольцам деревьев
- Исследовал деревянные конструкции древних сооружений для построения хронологических шкал
- Упоминается в работах А. Склярова в контексте критического анализа дендрохронологического метода
