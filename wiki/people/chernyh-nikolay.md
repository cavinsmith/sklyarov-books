# Николай Черных

**Николай Александрович Черных** — советский и российский археолог, соавтор фундаментального труда «Дендрохронология Восточной Европы» (вместе с [[people/kolchin-boris|Б.А. Колчиным]]). Один из ведущих специалистов по [[methods/dendrokhronologiya|дендрохронологии]] и археологии Северной Евразии.

## Ключевые факты

- Соавтор фундаментального труда «Дендрохронология Восточной Европы» (вместе с [[people/kolchin-boris|Б.А. Колчиным]])
- Специалист по [[methods/dendrokhronologiya|дендрохронологии]] — методу датирования по годичным кольцам деревьев
- Исследовал деревянные конструкции древних сооружений для построения хронологических шкал
- Упоминается в работах Склярова в контексте критического анализа дендрохронологического метода

## Значение для альтернативной истории

[[methods/dendrokhronologiya|Дендрохронология]] используется для калибровки [[methods/radiouglerodnoe-datirovanie|радиоуглеродного датирования]]. Однако Скляров указывает на ряд проблем:

- Замкнутость шкал (нельзя верифицировать без независимых методов)
- Возможные ошибки при построении длинных шкал
- Зависимость от принятой хронологии
