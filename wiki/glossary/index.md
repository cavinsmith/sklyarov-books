# Глоссарий

Термины и определения, используемые в работах по альтернативной истории и критике официальной исторической науки.

## Основные понятия

### Археологические термины
- **Мегалиты** — крупные каменные конструкции, возведённые без использования раствора (напр., менгиры, дольмены, циклопические кладки)
- **Геоглифы** — изображения на земле, созданные путём удаления верхнего слоя почвы (напр., линии Наска)
- **Стратиграфия** — метод датирования по слоям отложений

### Методы датирования
- **Радиоуглеродное датирование** — метод определения возраста по содержанию изотопа ¹⁴С
- **Дендрохронология** — метод датирования по годичным кольцам деревьев
- **Термолюминесцентное датирование** — метод определения возраста керамики

### Альтернативные концепции
- **Палеоконтакт** — гипотеза о контактах древних цивилизаций с инопланетными существами
- **Древние технологии** — неизвестные или утраченные технологии древних цивилизаций
- **Потоп** — глобальная катастрофа, упоминаемая в мифах разных народов

## Критика официальной науки

- **Консенсус** — общепринятое мнение в научном сообществе, которое альтернативные исследователи ставят под сомнение
- **Парейдолия** — склонность видеть значимые формы в случайных данных (используется для объяснения «аномалий»)
- **Цензура** — ограничение доступа к информации, противоречащей официальной версии
